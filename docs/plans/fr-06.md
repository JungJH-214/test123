## 위험 영역
- **락 전 엔티티 로딩 금지 (T2):** `cancel()`의 1단계는 회차 ID 값만 읽는다. `findById`로 엔티티를 먼저 읽으면 락 뒤에도 1차 캐시의 오래된 상태를 보고, 동시 취소에서 승급이 두 번 일어날 수 있다. reviewer는 이것을 반드시 본다
- **승급 기준 = D-04:** `findFirst...OrderByIdAsc`. `createdAt` 정렬을 쓰지 않는다
- **신청 경로 변경 (T2):** `enroll()`에 승급이 들어가므로 FR-04·FR-05 테스트(정원·대기 상한, 동시 신청 순번 {1..5})가 모두 그대로 통과해야 한다
- **시계:** `LocalDate.now()`를 직접 쓰지 않는다. 주입한 `Clock`과 `Asia/Seoul`만 쓴다
- **선행 PR:** FR-05·FR-07 병합 전 시작 금지. rebase 충돌은 양쪽 테스트를 모두 남기는 방향으로 푼다
- **공유 테스트 DB:** 새 동시성 테스트는 자기 데이터만 지운다. 기존 테스트의 `deleteAllInBatch()`와 동시에 돌면 깨질 수 있으니, 실패 시 단독 재실행으로 구분한다
